# Security

riskell runs as your user, draws windows over your screen, and (when you turn the options on) reads the Claude usage token from your
keychain, the trackpad, and OmniWM's settings. Compiled extensions run inside it with your rights and there is no sandbox.

**Report a vulnerability privately:** on GitHub, open this repository's *Security* tab and choose *Report a vulnerability*. Please do not
open a public issue for one. You will get an answer within a few days; this is a one-person project, so please be patient.

Supported: the latest release only.
